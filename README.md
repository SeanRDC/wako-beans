# Wako Beans

Five bags of Philippine coffee, from 1,800 metres in Benguet down to 310 in Batangas, covering all four coffee species. It is a portfolio concept that works like a real shop: browse, choose a size and grind, fill the bag, check out and get a confirmation. Nothing is charged and nothing ships.

It is the sibling of [Wako Matcha](https://wako-matcha.vercel.app/), with its own design.

## Run it

Node 24.

```sh
npm install
npm run dev        # http://localhost:3000
npm run build      # every page is prerendered
npm test           # unit tests (Vitest)
npm run lint
npm run typecheck
```
